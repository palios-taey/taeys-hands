# Project: taey-hub-unattended-loop - Qualify and release the unattended five-Chat loop
> Status: qualification plan, not the operating baseline. Preserve the current Tasks API as the only work authority, `taey-presence` as the worker/lease/transport authority, and `taeys-hands` platform YAML/drivers as the only UI authority; prove one clean five-display value-add batch, then prove two unattended revolutions before moving Codex out of routine UI supervision.

## Repository boundary

- `palios-taey/taeys-hands` owns packet construction, platform YAML, canonical trees, platform drivers, monitors, extraction, and consultation receipts. This plan is canonical here because the production outcome is a five-platform consultation campaign.
- `palios-taey/taey-presence` owns Taey worker serving, one-call tool exposure, seats/turns, display leases, and mechanical refusal of unproven next mutations.
- The current Tasks API remains the sole work queue and campaign authority. This plan does not authorize a second dispatcher or graph-task implementation.
- `infra-soul` is not an implementation or documentation surface for this work.
